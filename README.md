# Hokm Arena

A first Flutter UI prototype for the Hokm card game.

## Current status
This is only an early local UI prototype. Online matchmaking, real multiplayer networking, server-authoritative rules, secure/verifiable shuffling, accounts and anti-fraud systems are not implemented yet.

## Build APK
1. Open the repository's Actions tab.
2. Select **Build Hokm Arena APK**.
3. Tap **Run workflow** (or wait for the push-triggered build).
4. Open the completed run and download the `hokm-arena-apk` artifact.
5. Extract the downloaded ZIP to find `app-release.apk`.
